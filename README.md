# Address Book Management System in C

A console-based Address Book Management System developed using C programming.

## Features

- Add new contacts
- Search contacts
- Edit contact details
- Delete contacts
- Display contact information
- Store contact data using file handling

## Concepts Used

- C Programming
- Structures
- Pointers
- Functions
- File Handling
- Modular Programming

## Project Structure

The project is organized into multiple source and header files to keep the implementation modular and easy to maintain.

## How to Run

Compile and run the program using GCC.
